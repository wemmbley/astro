# Натал.

Натальная Карта - это набор планет, знаков, домов и аспектов между ними.

Каждый из них имеет свой градус, необходимый для трактовок.

## Запуск.

Для первичной установки проекта, миграций, и всего проче, выполните команду:
```bash
composer setup
```

Затем для запуска проекта выполните команду:
```bash
composer dev
```

## Модули.

| Имя модуля | Предназначение                                        |
|------------|-------------------------------------------------------|
| Geo        | Поиск координат города для Натала с помощью имени.    |
| Natal      | Сборщик JSON-Ответа от Python в красивые VO/Entites.  |
| Expositor  | Трактовщик, толкователь полученного Натала и Матрицы. |

## Clean Architecture.

Все модули хранятся в папке `app/Modules` с внутренним разделением на слои.

| Имя папки      | Предназначение      | Примеры           |
|----------------|---------------------|-------------------|
| Application    | Хранитель UseCase   | UseCase, Service  |
| Domain         | Хранитель логики    | VO, Entity, Logic |
| Infrastructure | Зависимости Laravel | Eloquent, Artisan |
| Presentation   | Слой представления  | Langs, Views      |
