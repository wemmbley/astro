# Астрологический сайт.

Натальная Карта - это набор планет, знаков, домов и аспектов между ними.

Каждый из них имеет свой градус, необходимый для трактовок.

Для авторизованных пользователей есть социальная сеть: друзья, подписки и так далее.

## Как запустить целостно?

Нам нужен сам сервер, затем редис, затем реверб, затем воркер, затем вит.

```bash
php artisan serve
php artisan reverb:start
php artisan queue:work
npm run dev
```

## Связь

Laravel инициализируется, и бутит Inertia.
Inertia инициализируется, создаёт роуты и прокидывает туда пропсы.
Vuejs инициализируется, где надо делает WebSocket либо fetch.

Роутинг фронта хранится в файле `src/UI/Routes/web.php`, контроллеры - `src/UI/App/Http/Controllers`.
