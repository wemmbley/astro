# Натальная карта.

## Как запустить?

`docker-compose up`

После чего добавить в `hosts`:
```
front.loc
laravel.loc
flask.loc
```

Теперь доступные следующие URL:
- http://front.loc/ для фронта
- http://laravel.loc/ для API Laravel
- http://flask.loc/ для API Flask

## Почему микросервисы?

Я оппозиционер микросервисам, но здесь - нужда. В PHP среде нет точных программ которые использовали бы эфиримиды и генерировали на их основании натал. Питон - необходимость.

Я пробовал делать великие фронты клиентские на голом JS, как итог - боль. React - необходимость.

Я триста миллионов раз писал свой аналог Laravel, как итог - боль. Laravel - необходимость, как сервер и слой доступа к БД.

Сделав два API на Python и Laravel, имея ещё и React как часть инфры - микросервисы напросились сами.

## Какая инфраструктура?

- `apps` - здесь все микросервисы, пока их лишь три, и вряд ли планируется больше.
- `infra` - настройка инфраструктуры, докера, nginx, php и тд.

## Какое будущее?

Я думаю просто взять хостинг под БД, хостинг под пайтон, хостинг под фронт и хостинг под ларавель. Это сразу распределит всю нагрузку не создавая боттлнеков.

Докер здесь скорее для удобства. В проде я не люблю его использовать. Слишком падает, слишком ненадёжен, слишком прожорлив. Лучше 4 CI/CD-Пайплайна, чем Kubernetes.
