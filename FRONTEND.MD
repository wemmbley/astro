# Сборка и запуск.

Для первичной установки проекта, выполните команду:
```bash
npm i
```

Затем для запуска проекта выполните команду:
```bash
npm run dev
```

# Архитектура

## Концептуально

Концептуально у нас архитектура строится вокруг Inertia.
Она решает вопрос SEO, SSR, роутинга и REST.

Вместо привычных `UI <-> API` стал `UI <-> Inertia`.

Это - ультимативное решение вместо Nuxt.js, воспринимайте его как новый
протокол передачи данных и обмена информацией сервер-клиент.
