# Натал.

## Алгоритм

1. Загружается фронт на React.
2. Фронт делает запрос на получение координат города.
3. Мы делаем запрос в сервис Geo и возвращаем координаты.
4. Фронт делает запрос на получение натала по координатам и времени.
5. Мы делаем запрос в сервис Natal и возвращаем натал. 
6. Дополнительно: по этим координатам и времени сервер создаёт кэш в бд.
