# Сценарии

- `AI` - всё, что связано с искусственным интеллектом.
- `Analytics` - анализ пользователя и его поведения на странице.
- `Geo` - работа с геоданными - вычисление страны по айпи, поиск городов и тп.
- `Natal` - натальный расчёт по дате рождения.
- `Social` - социальный слой кооперации и коммуникации: посты, профили, стены.
