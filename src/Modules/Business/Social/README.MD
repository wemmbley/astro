# Социал

У каждого пользователя есть публичный профиль с постами. Пользователи могут дружить,
подписываться друг на друга и иметь подписчиков.

## Модели

### UserFollow

Подписка одного пользователя на другого. Создаётся как только пользователь нажал «Подписаться»,
либо автоматически — как побочный эффект принятой заявки в друзья.

### UserFriendRequest

Заявка в друзья. Проходит через несколько статусов:

| Статус    | Суть                          | Побочный эффект                                  |
|-----------|-------------------------------|--------------------------------------------------|
| pending   | ждёт ответа получателя        | —                                                |
| accepted  | принята                       | создаются две записи `UserFriend` (A→B и B→A)    |
| declined  | отклонена получателем         | —                                                |
| cancelled | отозвана отправителем         | —                                                |

### UserFriend

Подтверждённая дружба. Появляется только после того, как `UserFriendRequest`
перешёл в статус `accepted`.

Если кто-то из двух удаляет другого из друзей — обе записи `UserFriend` удаляются,
но `UserFollow` сохраняется: удалённый остаётся подписчиком.

### UserBlock

Чёрный список. Блокирует просмотр профиля, постов и отправку сообщений.

При создании `UserBlock` каскадно происходит:
- удаление `UserFriend` (если дружба была)
- перевод `UserFriendRequest` в статус `cancelled` (если была активная заявка)

## Связь моделей

| Действие                  | Что происходит                                                             |
|---------------------------|----------------------------------------------------------------------------|
| Подписаться               | `UserFollow::create()`                                                     |
| Отписаться                | `UserFollow::where('follower_id', $id)->delete()`                          |
| Удалить подписчика        | `UserFollow::where('following_id', $id)->delete()`                         |
| Отправить заявку          | `UserFriendRequest::create(['status' => 'pending'])`                       |
| Принять заявку            | `UserFriendRequest::update(['status' => 'accepted'])` + `UserFriend` ×2    |
| Отклонить заявку          | `UserFriendRequest::update(['status' => 'declined'])`                      |
| Отозвать заявку           | `UserFriendRequest::update(['status' => 'cancelled'])`                     |
| Удалить из друзей         | `UserFriend::delete()` ×2, `UserFollow` остаётся                           |
| Заблокировать             | `UserBlock::create()` + каскадная чистка через Observer                    |
