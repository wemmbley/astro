# Модули

Модуль - это вектор движения Духа, оформленный в мифонарратив.

Он имеет три сюжета: актор, сцена и сценарии.

# Ось

- `Actors` - immutable domain, онтологчиеское ядро, вещь в себе, Идея, базовые примитивы Абсолюта.
- `Scenarios` - mutable business, реализация Актора с намерением, духовный замысел.
- `Scene` - infrastructure, зависимости от Laravel & 3rd-party сервисов.

# Зависимость

Суть: `Идея → Воля → Оформление`.

```
┌─────────────────────────────────────────┐
│                 SCENE                   │  (Внешний слой: контроллеры, API-клиенты, логгеры, Stripe)
│   ┌─────────────────────────────────┐   │
│   │           SCENARIOS             │   │  (Сценарии: расчет натала, расчёт матрицы судьбы, логика)
│   │   ┌─────────────────────────┐   │   │
│   │   │         ACTORS          │   │   │  (Абсолют: планеты, дома, арканы, формулы)
│   │   └─────────────────────────┘   │   │
│   └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```
