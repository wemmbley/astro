# Модули

Модуль - это вектор движения Духа.

Он имеет три оси: актор, сцена и сценарии.

# Ось

- `Scenarios` - изменяемая телеологическая реализация словаря, онтологии на практике с целевым намерением.
- `Actors` - неизменяемое онтологчиеское ядро предметной области, что вообще есть и каково оно, вещь в себе.
- `Scene` - это уже технически-инфраструктурный слой, не относится к сценариям и к онтологчиескому словарю.

# Зависимость

```
┌─────────────────────────────────────────┐
│                 SCENE                   │  (Внешний слой: контроллеры, API-клиенты, логгеры, Stripe)
│   ┌─────────────────────────────────┐   │
│   │           SCENARIOS             │   │  (Сценарии: расчет натала, расчёт матрицы судьбы, логика)
│   │   ┌─────────────────────────┐   │   │
│   │   │         ACTORS          │   │   │  (Абсолют: планеты, дома, арканы, формулы)
│   │   └─────────────────────────┘   │   │
│   └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```
