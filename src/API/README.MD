# API

Это - единый слой доступа к нашей внутренней API.

Здесь хранится роутинг и контроллеры.

Вся логика обязана быть вынесена в Modules.

# Версионирование

API обязано версионироваться, и наша первая версия зовётся `V1` по пути `Http/Controllers/API/V1`.

Если склад контроллеров начинает переполняется, допустим вынос в отдельные зоны - доменные папки.
