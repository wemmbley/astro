# UI Модули

UI-Модуль это специфическая доменная область, ответственная за один конкретный слой логики отображения.

# Архитектура

| Имя зоны | Предназначение                            | Пример          |
|----------|-------------------------------------------|-----------------|
| Domain   | Изолированная TS-логика.                  | NatalTypes.ts   |
| UI       | Всё, что касается UI. Зависим от движка.  | Natal.vue       |
| API      | Всё, что касается внешних fetch-запросов. | NatalFetcher.ts |

# Архитектура Domain-области

Здесь мы храним типы, маппинги, моки, картинки, иконки - в общем всё то, что нужно Домену.

Позже всё это добро мы будем использовать в UI-слое.

# Архитектура API-области

Здесь мы храним типы ожидаемых ответов от сервера, и сами запросы.

# Архитектура UI-области

## UI

UI это зона отражения пользовательских интерфейсов в модуле.

| Имя зоны     | Предназначение                                      | Пример     |
|--------------|-----------------------------------------------------|------------|
| Components   | Atomic Design разбивка компонентов.                 | Button.vue |
| Templates    | Готовые композиции под будущее использование в Page | Natal.vue  |

## UI/Components

Все UI компоненты используют 3 базовых типа из Atomic Design.

| Имя зоны  | Предназначение                                                    | Пример         |
|-----------|-------------------------------------------------------------------|----------------|
| Atoms     | Атомарные, переиспользуемые, независимые элементы.                | Button.vue     |
| Molecules | Небольшие сборные солянки из атомарных элементов.                 | Modal.vue      |
| Organisms | Крупные организмы, которые используют комплексов Атомы и Молекулы | NatalChart.vue |
