# Пейджи

Поскольку мы не хотим, чтобы рядовой пользователь имел доступ ко всем страницам сайта,
мы разделили зоны ответственности пейджей.

Теперь доступ зависит от области, в которой находится пейджа. Например, область Admin
доступна только уполномоченным авторизованным администраторам.

# Формат

Все пейджи имеют Vue-формат файлов, поскольку это наш основной фронт-енд движок.
