# Модульная Архитектура

Проект построен так, чтобы не развалился через год.
Строгое разделение зон ответственности: API, Web и логика.

## Схема Monolith UI

```
Controller -> Module -> Props --+
                                |
                         UI <---|
```

## Схема Monolith API

```
UI -> API -> MODULE --+
                      |
         Response <---|
```

## Почему две связки?

Первичная связка нужна для SSR (во имя SEO) от Inertia +Laravel routing для Vue пейджей.

Вторичная связка нужна когда данные нужно подгрузить динамически с сервера, а не разово при старте.
