# Модульная Архитектура

Проект построен так, чтобы не развалился через год.
Строгое разделение зон ответственности: API, Web и логика.

## Схема Monolith UI

```
UI(Controller) -> MODULE -> UI(Vue.Props) --+
                                            |
                                     UI <---|
```

Из зоны UI вебконтроллер идет в зону Module, и доставляет оттуда логику в пропсы Vue через Inertia.
Мы не пытаемся играть в микросервисы, это - монолит. Поэтому взаимодействия слоя UI с Module - норм.

## Схема Monolith API

```
UI -> API -> MODULE --+
                      |
         Response <---|
```

Тут уже четкая логика сепарации слоёв. UI слой ничего не знает об внутрянке API, а тот уже знает про модули.

## Почему две связки?

Первичная связка нужна для SSR (во имя SEO) от Laravel Blade через Inertia для Vue пейджей через роутинг Laravel.

Вторичная связка нужна когда данные нужно подгрузить динамически с сервера, а не разово при старте. Это уже runtime-load.
