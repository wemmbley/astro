# Астро-расчёт Натальный.

Здесь производится ручной расчёт натальной карты на основании Swiss Ephemeris.

Это - эталонный калькулятор. Механизм сделан так, что он в accuracy-100% попадает во все именитые сайты по астрологии.

# Архитектура

| Имя файла       | Предназначение                             |
|-----------------|--------------------------------------------|
| `astro-core.py` | Главный движок                             |
| `config.py`     | Настройки приложения                       |
| `chart_svg.py`  | Генерация окружности визуальной для Натала |
| `server.py`     | API-сервер                                 |

# Эферемиды

Для работы сервиса рядом должна лежать папка `ephe` с эферемидами.

Скачать её можно прямиком отсюда: <a href="https://github.com/aloistr/swisseph/tree/master">Ссылка на репо</a>

```

```

# Эндпоинты

Можно посмотреть прямо в браузере: http://localhost:8020/docs

## 1. Натальный расчёт (данные)

`POST localhost:8020/chart/data`

Возвращает планеты, дома, алхимию, ASC, MC. Без SVG — быстрый, грузится первым.

| Параметр            | Пример             | Значение             | Статус       |
|---------------------|--------------------|----------------------|--------------|
| `birth_datetime`    | `22-12-2000 16:30` | Точная дата рождения | Обязательно  |
| `lat`               | `49.9833`          | Широта (десятичная)  | Обязательно  |
| `lon`               | `36.25`            | Долгота (десятичная) | Обязательно  |
| `planets`           | `["Sun","Moon"]`   | Нужные планеты       | Опционально  |
| `aspects`           | `["Square"]`       | Нужные аспекты       | Опционально  |

> ⚠️ Координаты передавать в десятичных градусах для точности.
> `49°59'` → `49.9833`, а не `49.59`

---

## 2. SVG-колесо карты

`POST localhost:8020/chart/svg`

Те же параметры, что у `/chart/data`. Возвращает только SVG.
Вызывается лениво после загрузки страницы — не блокирует LCP.

| Параметр            | Пример             | Значение             | Статус       |
|---------------------|--------------------|----------------------|--------------|
| `birth_datetime`    | `22-12-2000 16:30` | Точная дата рождения | Обязательно  |
| `lat`               | `49.9833`          | Широта (десятичная)  | Обязательно  |
| `lon`               | `36.25`            | Долгота (десятичная) | Обязательно  |
| `planets`           | `["Sun","Moon"]`   | Нужные планеты       | Опционально  |
| `aspects`           | `["Square"]`       | Нужные аспекты       | Опционально  |

---

## 3. Health check

`GET localhost:8020/health`

Параметров нет. Возвращает `{"status": "ok"}`.
