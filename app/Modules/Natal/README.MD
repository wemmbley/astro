# Натал

Эта доменная зона отвечает за генерацию Натальной Карты человека из даты, времени и места
его рождения, оформляя ответ в красивый VO или чистый примитив `array`.

Доменные термины:
- Натал - это Натальная Карта человека, сборка планет, знаков, аспектов и элементалей в кучу.
- Планета - это условный архетип интерпретации, который зависит от реального положения Планеты
в момент рождения человека.
- Знак - это условный архетип интерпретации, который можно интепретировать сам по себе, или в
контексте другой планеты-дома.
- Аспект - это условый архетип отношений для интерпретаций, чтобы понимать, как планеты и куспиды
связаны между собой.
- Куспид - фиксированная точка старта дома в градусе `00.0*`, которая всегда находится в знаке.

## Flow

Приложение проходит следующий путь:
```
UseCase(GenerateNatal) -> NatalCacheService -> PythonClient -> PythonResponseMapper --+
                                                                                      |
                                                                     VO(Natal) <------+
```

| Сервис               | Предназначение                                                                               |
|----------------------|----------------------------------------------------------------------------------------------|
| GenerateNatal        | Сценарий генерации всего Натала.                                                             |
| NatalCacheService    | Redis кэширование и отдача уже готового Натала из памяти, если есть.                         |
| PythonClient         | Адаптер запросов на Python сервер, где производится расчёт, если кэш оказался пуст.          |
| PythonResponseMapper | Маппер ответа Python сервера в нашу оболочку (DTO + VO) для удобства                         |
| Natal                | ValueObject всего Натала, который можно конвертировать целиком в массив через `->toArray()`. |

Таким образом, мы снимаем нагрузку с сервера Python, так же умеьшая latency
ожидания пользователя, кэшируя уже готовые карты, чтобы пользователь получал
их мгновенно "на лету" из памяти Redis по запросу.

На втором этапе мы оборачиваем сырой JSON-Response Python-сервера через маппер
в наши сущности доменной области. Домен остается статичным, Python может менять
свои ответы сколько угодно, мы не зависим от него. Нужно лишь маппер модифицировать.

## Конвенция интерпретаций

Каждая новая интерпретация должна лежать в соответствующей папке языка по адресу:
`Natal/Presentation/Lang` в субдиректории, в зависимости от языка. Например `Ru`.
