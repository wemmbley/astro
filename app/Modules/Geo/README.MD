# Geo.

Сервис необходим для уточнения координат по месту жительства.

Занимается парсингом `*.txt`-файлов городов, загрузкой их в БД и поиском в БД.

Парсер, импортер, поисковик. Концернов много, но пока нет необходимости их разграничивать. Парс и импорт еденичные процедуры.

# Источник.

Если нужно расширить список городов, то во-первых мы расширяем миграцию новой табличкой, во-вторых берем нужный `*.txt`-файл конкретного города отсюда:

https://download.geonames.org/export/dump/
